# 可计算双例判据：理论笔记与验证（v2，2026-10-07，8 分线尝试）

代码：`sign_criterion.py`（审计：`sign_criterion_audit.py`，全项通过）；
数据：`results/signcriterion_{cora,dblp}.json`。
v1 → v2 的修正记录在 §6（含一处健全性 bug 与两处建模错误，均由审计
暴露并修复——这也是本笔记可信度的来源）。

## 1. 设置

- 算子类：对称非负权超图团算子，热流 Z_t=(I−hB)Z_{t−1}，
  h=1/λmax(oracle)。
- 信道：对称 C 类腐蚀（率 p，ρ=p/(C−1)）；A=全预测一致边（thinning，
  与腐蚀相关）；B=oracle+匹配边际独立翻转（含混合边重连）。
- 初始化：φ-耦合 one-hot（腐蚀节点以率 φ 携带同一批错误预测）。
- 对象：E[Δ]=E[m̄^A−m̄^B_T]=p·G+(1−p)·D（论文 Prop criterion (i)）。

## 2. 可证部分

**命题 1（隔离保真，全 φ）** 条件于 W_u=1，u 在 A 中无边的概率
≥1−ε_u（闭式并集上界；ε̄ 的 MC 直测见审计 C2：闭式 0.037 vs 实测
0.027，有效但保守 ~40%）。设 disp(p,T) ≥ |m^A_T(u)−m_u(Z0)| 对一切
u、实现成立（A-only 实测常数，见 §3）。则

  |E[m^A_T|W=1] − (1−2φ)| ≤ ε̄·disp(p,T)。

这是论文 2R_m·ε̄（R_m=1）的收紧：实测 disp 虽可近 2（个别重连节点
翻号），但乘 ε̄ 后 slack ≈ 0.05，且隔离闭式本身在两数据集全 φ 全深度
偏差 ≤0.013（sign_predict 审计 A4）。

**命题 2（B 独立性，φ=0）** truth 初始化下 m^B_T(U)⊥W_U，故
E[m^B|W=1]=m̄^B_T。

**定理（双例充分条件）** 定义实例可算量 β̂（§3）、D̂（§3）、ε̄·disp，
及松弛 δ≥|E[m^B|W=1]−β̂|、ν≥|D−D̂|。则

  (P)  p·[(1−2φ) − slack − (β̂+δ)] + (1−p)·(D̂−ν) > 0  ⟹  E[Δ]>0
  (N)  p·[(1−2φ) + slack − (β̂−δ)] + (1−p)·(D̂+ν) < 0  ⟹  E[Δ]<0

*证明*：全期望 + 命题 1 双侧界 + 三角不等式。**N 必须用 D 的上界
D̂+ν**（Δ 的上界）——v1 曾误用 D̂−ν，审计 C1 暴露后修正。∎

## 3. 实例可算构件（不触碰 A−B 差异）

- **β̂（B-only 蒙特卡洛，主用）**：直接模拟模型 B 动力学（truth 初始化
  的总体均值 = β_c；耦合初始化下腐蚀节点均值 = β_w；各 100 实现）。
  δ(φ) 用 B-only 实测量验证：cora 0.001–0.007、dblp 0.0005–0.003。
  闭式参照（均值场 Ē_B + 探针流）保留在 JSON，误差 0.05–0.17，仅作
  对照。**教训**：错误初始必须用代表类 one-hot（margin 泛函与行混合
  不对易）；热流减号使邻域异类质量先变负，B 确实不恢复（β_w≈−1）。
- **D̂(p,T,φ) = D_thin − Û(pφ)**：
  D_thin = Ŝ(r_A)−Ŝ(r_B)+T̂(r_A^het)−T̂(r_B^het)，S/T 为 oracle 图
  随机移除 hom / 加入 het 边的饱和响应曲线（r 网格自适应至 0.5·m_hom）；
  逐边保留率 ph_e=Σ_c(1−p)^{n_c}ρ^{k−n_c} **必须按类计数**（v1 曾对
  混合边误用同质公式，导致 r_B^het 虚高 24 倍、D_thin 反号——审计
  C3 暴露后修正）。
  Û(f)：Ē_B 上把 f 比例节点翻成代表错误类、未翻转节点均值 margin 的
  **上升**量（>0）。机制：错误邻居对干净节点的拉扯变弱、B 侧干净
  节点衰减更慢、margin 上升 → D=m^A−m^B 下降。A 侧腐蚀邻居被隔离
  （算子零行）不传播，故 φ 依赖全在 B 侧且符号为负（v1 曾误加，
  诊断数据定位后修正）。修正后 D 模型近乎精确：**ν_S：cora
  max 0.0022 / mean 0.0007；dblp max 0.0332 / mean 0.0156**。
- **disp(p,T)**：A-only 实现上 max_u|m^A−m_u(Z0)|（couple 初始化，
  最保守）。
- 竞争结构：D<0 ⟺ 同质稀释项 Ŝ(r_B)−Ŝ(r_A) 压过混合重连项
  |T̂(r_B^het)|+Û 修正——全部闭式/算子级可算，两数据集所有
  (p,T,φ) 上 D̂<0 且与实测同号（审计 C3）。

## 5. 认识论分层（如实）

1. 定理归约：无假设（除论文已有 R_m 地位的 disp 常数）。
2. β̂：B-only 模拟，δ 由 B-only 量验证——不触碰 A−B。
3. D̂：构件全为 oracle/B-only 量，但松弛 ν_S 的**验证**用了 D
   （A−B 下游差）→ 假设 (S)，与 R_m 同地位，比 8 分理想弱一档。
4. strict 档只剩 cora 2 个 N；dblp 被 A-clean 逐模型误差 0.126 阻塞。

## 6. v1→v2 修正记录（审计驱动）

- C3：D_thin 反号 → 根因 retention_table 对混合边误用同质公式

- 隔离松弛 2R_m·ε̄ → ε̄·disp。

## 8. APPNP 算子类扩展（预注册，cora，α=0.9，对称归一化+自环）

论文 §dblp 约定：S = D^{-1/2}(A+I)D^{-1/2}（二元边），Z←αSZ+(1−α)Z₀。
自环使被隔离节点满足 SZ₀=Z₀ ⟹ **隔离闭式 1−2φ 原样成立**（实测全 φ
偏差 ≤0.026，含端点 −0.997 vs −1.00）；β(φ) 仍线性（逐差散度 0.007）。

- **7 分线规则迁移**（完整 cal→predict→eval，全新种子）：margin 符号
  v2 61/65 (94%)、v1 64/65 (98%)，acc 106/111 (95%)。转折比热流平坦
  得多（p=0.1: φ* 0.14→0.34；p=0.2: 0.12→0.27 vs 热流 0.06→0.49）：
  重启锚定状态，深度效应被抑制。
- **机制级符号翻转全部被组件模型预测对**（这是框架普适性的核心证据）：
  (i) D 由热流的负变为**正**（实测 +0.0005..+0.063；Û<0——APPNP 的
  正向混合没有热流的减号排斥，错误邻居确实伤害 B 的干净节点）；
  (ii) β_w 由 −1 变为 **≈−0.6**（重启+邻居拉扯部分恢复腐蚀节点），
  G(φ=1) 从 ≈0 变为 ≈−0.4（强负，A 在耦合端更吃亏）。
- **证书**：0 个（当前构件精度下）。阻塞点已量化：slack_iso=0.068
  （disp≈2.89——对称归一化+重启下 margin 可越出 [−1,1]，max-位移
  界粗）与 D̂(1) 过冲 ~17%（Û 采样图 vs 实测残差 0.006）。修复路径：
  Cauchy–Schwarz 松弛 sqrt(ε̄·E[δ²])≈0.028（δ² 为 A-only 二阶矩）+
  Û 精化；预计可解锁 N 证书（当前 N 裕度仅差 0.005–0.013）。
- 结论：判据**框架**（分解 + 隔离闭式 + 逐算子组件测量）在两类算子、
  两数据集上结构成立；严格证书目前仅热流-cora（N2）。适用边界：
  证书档需 disp 有界（热流 ✓ / APPNP 需 CS 松弛），D 模型精度决定
  P/N 覆盖。

## 9. 最后一档锐化与终态（2026-10-07）

两项修正（审计后全绿）：

1. **隔离松弛 → Cauchy–Schwarz**：|E[δ·1{¬iso}]| ≤ sqrt(ε̄·E[δ²])，
   E[δ²|W=1] 为 A-only 二阶矩（MC 实测，+3SE 保守化）。层级自洽：
   E[δ²] ≤ ε̄·disp² 时退化回旧界 ε̄·disp。实测把 slack 从 0.048–0.068
   压到 ~0.017（heat-cora）/ ~0.028（appnp）。
2. **Û 随机错误类**：固定平移类 (y+1) mod C 使同类错误邻居总推同一类、
   接收端 max-other 质量过度集中（APPNP 正向混合下 ~17% 过冲的机制）；
   改为逐节点独立随机错误类后 ν_S(appnp) 0.0065→0.0047。

**终态证书（全部 0 假证书，审计复算一致）**：

| 设置 | strict 档 | (S)-档 | 覆盖 | ν_S max |
|---|---|---|---|---|
| cora / 热流 | N 8 | **P 12 + N 53** | **64/72 (89%)** | 0.0019 |
| dblp / 热流 | 0 | N 58 | 58/83 (70%) | 0.0314 |
| cora / APPNP | N 2 | **P 10 + N 33** | 41/68 (60%) | 0.0053 |

全部 24 个 (p,T) 面板呈 **P 带(低 φ) | 实测 φ* | N 带(高 φ)** 的夹逼
结构，不确定带包含其余转折；sign(D̂)=sign(D_meas) 在三设置全部成立
（算子无关检查）。

**剩余边界**：dblp 的 P 方向仍 0（ν_S(dblp)≈0.015 均值 + slack，需

## 16. 依赖强度干预实验（评审第七轮首选，2026-10-07）

**设计**：固定图/标签/噪声率/逐边规则/线性算子，超边随机分 K 组，
每组独立节点预测、组内共享。K=1=A；K=m 的 â_e 为独立
Bernoulli(ph_e)，与 B 在任何 {â_e} 泛函上同律（三重端点一致性
K=m≈B≈V0 为内置检验）。逐边边际全程不变，仅跨边依赖变化。

**理论（精确，可推导）**：随机分组平均下
E‖ΔB−EΔB‖²_F = V0 + C1/K，V0=Σ_e ph_e(1−ph_e)，
C1=Σ_{e∩f≠∅} Cov₁·|e∩f|²/(k_e k_f)——**不相交边对 Cov₁=0，
相关全部经由共享节点**（主问题的定量形式）。谱范数随 K 无推导，
实验检验。代码 dependency_intervention.py（稀疏 eigsh；本机稠密
SVD 340ms/次曾是瓶颈）。

**结果（合成 3 种子 ×2p 试点 → 门槛全过 → Cora/DBLP 扩大）**：

| 结构 | 仿射 R² | 截距/斜率 vs 闭式 | 端点 | 中心化谱范数 K=1→m | B |
|---|---|---|---|---|---|
| 合成×6 | 0.989–0.999 | ≤4% 偏差 | K=1≈V0+C1；K=m≈B≈V0 | 2.44→1.71 | 1.69 |

| DBLP (C=6) | 0.9999/1.0000 | 3300.7/3302.8；1596.7/1590.8 | 全吻合 | 6.39→2.76（2.3×） | 2.68 |

**结论**：在保持逐边边际不变的受控干预下，二阶量精确遵循可推导的
1/K 仿射律（截距=独立值、斜率=共享协方差），中心化谱范数在全部
10 个（结构×p）组合单调下降并收敛到 B 值——"两种机制有差异"升级为
"对依赖的受控干预 + 理论定量验证"。**边界（如实）**：谱范数单调性
是实验事实非推导；干预识别的是指定对称信道下的依赖作用，不自动
